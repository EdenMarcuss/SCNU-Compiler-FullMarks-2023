## 这是什么

按照华南师范大学计算机学院《编译原理课程项目》任务书（2023.01）实现的完整参考实现，覆盖任务书全部必做内容与选做内容：

| 任务书要求 | 本仓库实现 |
|---|---|
| 项目一(1) 文本文件输入语言全部单词的正则表达式 | ✅ 打开文件 + 预设 TINY / Mini-C 词法，支持 `a..z` 区间、字符类、转义、`宏` 辅助定义（不参与扫描优先级） |
| 项目一(2)(3)(4) 正则→NFA→DFA→最小化DFA，界面呈现 | ✅ Thompson 构造 + 子集构造法 + 划分精化最小化，状态转换表（列按等价合并，如 `a..z` 一列）+ 状态图双视图 |
| 项目一(5) 生成 C 语言词法分析程序并展示 | ✅ 内嵌最小化 DFA 转移表 + 最大匹配扫描，页内可直接下载 `.c` 文件 |
| 项目一(6)(7)(8) 编译运行、TINY 测试、输出 sample.lex | ✅ 页内执行与生成 C 逻辑完全一致；sample.lex 输出格式与原作业「代码行回显 +（类别，词素）」**逐词一致** |
| 项目二(1)-(5) BNF 输入、化简、消左递归/左公因子、First/Follow、LL(1) 表 | ✅ 全自动：文法化简、间接左递归消除、带替换展开的左公因子提取（迭代至不动点）；TINY 与 Mini-C 文法变换后 LL(1) 表均无 FIRST/FIRST 冲突，悬空 else 按「最近嵌套」规则自动消解 |
| 项目二(6)(7) LL(1) 分析 + 语法树 + sample.lex 测试 | ✅ 完整分析栈轨迹（119 步逐行展示）+ 可视化分析树；可直接打开 sample.lex 文件作为输入，与项目一串联 |
| 项目三 Mini-C 全流程测试（自编源程序） | ✅ 一键运行：词法→语法→AST→四元式，附测试报告（`自己编写的mini-c源程序.txt` 按任务书要求自行编写） |
| 选做 中间代码（四元式） | ✅ TINY 与 Mini-C 均生成四元式（赋值/算术/关系/跳转/label，Mini-C 含 call/param/数组存取/return） |

**质量验证**：36 项自动化测试全部通过（`source/test.mjs`），覆盖词法正确性（与原 sample.lex 对拍）、文法变换、LL(1) 分析、AST/四元式生成与边界错误处理；界面经 Chromium 实测。

## 怎么用

1. 下载 `编译原理课程项目-满分重制版.html`，双击用 Chrome / Edge 打开。
2. 顶部三个标签页对应三个项目；每个面板右上角有一行「这一步在干什么」。
3. 顶部控制条可切换 TINY / Mini-C 预设，或打开本地正则 / 文法 / 源程序文件（自动兼容 UTF-8 与 GBK 编码的老作业文件）。
4. 想真的编译生成的 C 词法分析器：下载 `.c` 后 `gcc TINY_lexer.c -o lexer && ./lexer sample.tny`。

## 给学弟学妹

从 2022 级起这门课已经改革：大项目拆成了 4~5 个独立实验，LL(1) 换成了 LALR(1)，四元式从选做变成了必做。但拆开看，每个实验的内核算法**一个字没变**——本仓库的每一块仍然精确对应你手上的实验：

- `正则 → NFA → DFA → 最小化` = 实验二（RegexToDFA）
- `文法化简 / First / Follow / 分析表 / 语法树` = 实验三、四（TinySyntaxTree / LALR）
- `四元式中间代码` = 实验五

建议的用法：先自己啃，卡住时来这里看「这一步的完整推导长什么样」，对着表格理解算法在做什么——直接抄代码应付作业，只会把当年前人 70 分的老路再走一遍。

## 目录结构

```
├── 编译原理课程项目-满分重制版.html   # 全部功能的单文件应用（含内嵌预设与算法）
├── sample.tny                        # TINY 测试源程序（阶乘）
├── 自己编写的mini-c源程序.txt          # 按任务书要求自编的 Mini-C 测试程序
└── source/                           # 算法与界面源码（可独立维护、重新构建）
    ├── core.js                       # 核心算法库：正则/NFA/DFA/最小化/C生成/词法 + 文法/LL(1)/AST/四元式
    ├── presets.js                    # TINY 与 Mini-C 的正则表、BNF 文法、测试源程序
    ├── app.js                        # 界面装配（三个标签页、表格/树/自动机渲染、文件读写）
    ├── style.css                     # 样式（浅色主题）
    ├── build.py                      # 构建脚本：源码 + 预设 → 单文件 HTML
    └── test.mjs                      # 36 项全链路自动化测试（node test.mjs）
```

核心算法清单：Thompson 构造 · ε-闭包 · 子集构造法 · 划分精化（DFA 最小化）· 最大匹配扫描 · 文法化简（无用符号消除）· 左递归消除（含间接）· 左公因子提取（含 FIRST 冲突替换展开）· FIRST/FOLLOW 不动点计算 · LL(1) 预测分析表（FIRST 优先于 FOLLOW 的冲突消解）· LL(1) 栈式分析 · 递归下降 AST 构建 · 四元式代码生成。
